# **App Name**: Sudoku Solver Assistant

## Core Features:

- Empty Sudoku Grid: Display a blank 9x9 Sudoku grid with the standard 3x3 block divisions.
- Manual Value Input: Allow the user to input known values into the Sudoku grid. Input should be constrained to digits 1-9.
- Next Value Calculation: Calculate the next logical value to insert based on standard Sudoku solving techniques and mathematical algorithms (non AI at this stage).
- Cell Highlighting: Highlight the cell where the calculated value should be placed.
- Value Display: Display the calculated value that should be placed in the highlighted cell.
- Reasoning Explanation: Provide a textual explanation of the reasoning behind the calculated value, describing the Sudoku solving technique used, acting as a helpful tool to assist user understanding and training.

## Style Guidelines:

- Primary color: Soft blue (#89B4FA) to create a calm and focused atmosphere for puzzle-solving.
- Background color: Very light blue (#F0F5FF) to minimize distraction and maintain clarity.
- Accent color: Muted orange (#C77800) to draw attention to the highlighted cell and calculated value, without being jarring.
- Body and headline font: 'Inter', a sans-serif font, will be used for both body text and headlines, for a clean and legible presentation.
- Simple, clear icons will be used for any interactive elements such as buttons or settings.
- A clean, minimalist layout will prioritize the Sudoku grid and related information, avoiding unnecessary clutter.
